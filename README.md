# SelectPdf how-to guides: C# samples

Complete, runnable C# programs for common PDF tasks in .NET with [SelectPdf.Universal](https://selectpdf.com/pdf-library-cross-platform/), one project per guide. Each sample is compiled and run before it is published: on Windows x64, Linux x64, Linux ARM64 and macOS on Apple Silicon, and the cloud samples in the cloud's own image, and explained step by step on [selectpdf.com/how-to](https://selectpdf.com/how-to/).

## Run a sample

```bash
cd merge-pdfs
dotnet run
```

Requires the .NET 10 SDK. Each project references `SelectPdf.Universal` and the engine package for the machine that builds it (Windows x64/x86, Linux x64/ARM64, macOS on Apple Silicon). Without a license key the output carries a trial watermark: set `SELECTPDF_LICENSE_KEY` to remove it.
